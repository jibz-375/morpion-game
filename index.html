Guide : Recréer ce jeu sur GDevelop

Structure pas à pas des variables, événements et logique pour Poki.

1. Objets & Sprites nécessaires

Cellule (Sprite)

3 animations : 0=Vide, 1=X, 2=O. Créez un groupe de 9 instances sur la scène disposées en grille 3x3.

WinningLine (Sprite)

Une barre fine colorée. Changez son angle et sa position pour couvrir les 8 lignes gagnantes possibles.

Textes UI

Objets texte pour afficher le score de X, O, les Égalités et l'état du tour ("Tour de X").

2. Variables de Scène (Scene Variables)

Nom de Variable Type Description / Valeurs
CurrentTurn Texte / Chaîne "X" ou "O"
GameMode Texte / Chaîne "2P" ou "AI"
Difficulty Texte / Chaîne "SuperEasy", "Easy" ou "Hard"
GameState Texte / Chaîne "Playing", "Won", "Draw"
Board (Tableau/Structure) Array (Taille 9) Stocke l'état des cases (ex: ["X", "", "O", ...])

3. Logique des Événements clés

A. Clic sur une Cellule (Joueur Humain)
  • Conditions : Souris/Toucher est sur Cellule + Clic gauche enfoncé + Animation de Cellule == 0 + GameState == "Playing".
  • Actions : Set Animation de Cellule à (1 pour X, 2 pour O). Jouer son "Click". Mettre à jour le tableau Board[Cellule.Variable(Id)]. Lancer l'événement de vérification des conditions de victoire.
B. Tours de l'IA (Mode Robot)
  • Conditions : GameMode == "AI" + CurrentTurn == "O" + GameState == "Playing".
  • Actions : Déclencher un minuteur (ex: 0.3 sec pour l'effet de réflexion). Utiliser l'extension JS ou une fonction d'événement pour choisir la meilleure case disponible (Minimax ou aléatoire si Facile), puis Simuler un clic sur cette case.
C. Détection de Victoire
  • Créer une fonction/sous-événement testant les 8 combinaisons (0-1-2, 3-4-5, 6-7-8, 0-3-6, 1-4-7, 2-5-8, 0-4-8, 2-4-6).
  • Si 3 symboles identiques sont alignés : passer GameState à "Won", incrémenter le score du gagnant, afficher et orienter l'objet WinningLine, et jouer un son d'applause.

4. Intégration pour Poki

1. Dans GDevelop, installez l'extension officielle Poki SDK depuis le magasin d'extensions intégré.

2. Au démarrage du jeu, appelez l'action Poki :: Commercial Break pour charger le SDK.

3. À la fin de chaque partie (Victoire ou Égalité), ajoutez l'action Poki :: Gameplay Stop puis Poki :: Commercial Break pour diffuser une publicité rémunératrice avant la relance de la partie.
